# Life RPG

App de desarrollo personal gamificada: personajes, XP, monedas, misiones, inventario, armaduras, rankings y suscripciones.

## Requisitos

Node.js 22 o superior.

## Uso

```bash
npm install
npm start        # servidor de desarrollo (Expo Go / emulador Android / web)
npm run check    # typecheck + lint + formato + tests
```
