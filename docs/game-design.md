# Diseño del juego

> Borrador. Lo completará el agente Game Designer en la Fase 3.

## Visión

Convertir hábitos y metas reales en progreso de un personaje.

## Bucle principal

Completar misión real → recompensa (XP, monedas) → subir de nivel / comprar equipo → nuevas misiones.

## Sistemas

- Personaje (atributos, nivel, clase)
- Misiones (diarias, semanales, rachas)
- Economía (monedas, tienda, inventario, armaduras)
- Rankings (temporadas)
- Suscripción (beneficios premium, sin pagar para ganar)
